# TRAVOO — PRD

## Original problem statement
Pan-India intercity paid carpooling app (BlaBlaCar model) called TRAVOO, tagline "ENJOY YOUR RIDE." Drivers publish trips; passengers search, book and pay drivers directly by Cash/UPI (NO payment gateway, NO wallet, NO commission). Driver earnings ledger, driver verification with admin approval, 22 scheduled languages + English, India-wide location search with aliases/native scripts, chat, notifications, safety, cancellations, legal/compliance, admin dashboard. Brand: Navy #073B82, Blue #0875D1, Orange #FF7900, BG #F5F8FC, Text #172B4D.

## User choices
- Login: Email/password (JWT) + Emergent-managed Google sign-in
- Languages: AI-translated, marked "pending review"
- Places: built-in real list + OpenStreetMap (Nominatim) search
- Admin: inside the app (separate web dashboard later)
- Driver approval required, plus admin "instant approval mode" toggle

## Architecture
- Expo Router (SDK 58) frontend: tabs Home/Search/Offer/Bookings/Profile (NativeTabs on iOS 26+), screens trip/[id], booking/[id], chat/[id], earnings, driver, notifications, support, legal, admin, language, auth
- i18n: src/i18n (23 JSON locales generated by backend/scripts/translate.py using GPT via Emergent key; RTL for ur/ks/sd)
- FastAPI single server.py + seed_data.py, MongoDB (geo 2dsphere indexes, unique ledger index, atomic seat reservation, sparse unique active_key for duplicate-booking prevention)

## Implemented (Nov 2026)
- Auth (JWT + Google), consent, suspension
- Location search: 36 states/UTs + ~140 real places w/ aliases (Bangalore/ಬೆಂಗಳೂರು/बेंगलुरु), PIN prefix, OSM fallback (cached), current location reverse geocode
- Driver verification (licence/RC numbers, masked), vehicles, trip publish w/ stops, preview, edit, cancel, start, complete
- Search with geo radius, sort/filters, alternative dates
- Booking (instant or request), accept/reject, overbooking prevention, cancellation w/ reasons + refund note, settlement (cash/UPI declared by driver)
- Earnings dashboard + append-only ledger; reviews; chat (polling); i18n notifications; tickets/report/SOS (112 info only)
- Admin: stats/analytics, drivers approve/reject/resubmit, users suspend, trips, bookings, complaints, reviews hide, popular routes, settings (instant approval, cancellation hours)
- Legal drafts + compliance checklist (English, pending legal review)
- Tested: iteration_1 — 23/23 backend tests, frontend flows pass; admin crash fixed; settle/duplicate-booking made atomic
